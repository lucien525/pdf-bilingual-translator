# 📖 PDF / Word / PPT 翻译器 + 作业解题器

本文件夹里放着两个独立程序：

  翻译器 —— 把 PDF / Word / PPT 保留原排版翻译成 12 种语言
            启动：双击 重启翻译器.bat      端口：7860~7869
            输出：trans_result\ 文件夹

  解题器 —— 给作业 PDF / Word / PPT 自动写答案 + 解析
            启动：双击 启动解题器.bat      端口：7870~7899
            输出：homework_result\ 文件夹

两个程序互相独立，可以同时开着跑，不会冲突。


============================================================
一、第一次使用（10 分钟搭好）
============================================================

第 1 步：装 Python 环境

  需要 Miniconda（一个轻量的 Python 环境管理工具）。

  1. 下载：https://docs.conda.io/en/latest/miniconda.html
  2. 安装时勾选 "Add to PATH"
  3. 安装完，重启电脑


第 2 步：创建虚拟环境

  按 Win + R，输入 cmd，回车。依次执行：

      conda create -n trans python=3.10 -y
      conda activate trans

  （第一行创建环境，只需一次；第二行激活环境，每次都要）


第 3 步：安装依赖

  cd 到本项目目录：

      cd /d D:\file\translate\bilingual

  然后：

      pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

  加 -i 是国内镜像，装得快。约 3~4 分钟。


第 4 步：配置 API Key

  打开项目文件夹，找到 .env.example。

  右键 → 重命名，改成 .env（去掉 .example）。

  用记事本打开 .env，改成：

      DEEPSEEK_API_KEY=sk-你的密钥
      DEEPSEEK_MODEL=deepseek-chat

  去哪拿 API Key？  https://platform.deepseek.com


第 5 步：准备中文字体

  把 SourceHanSerifSC-Regular.otf（思源宋体简体版）放到：

      D:\file\translate\word_type\

  程序会自动扫描这个目录。放进去就行，不用改代码。


第 6 步：启动

  翻译器：双击 重启翻译器.bat
  解题器：双击 启动解题器.bat

  浏览器会自动打开界面。


============================================================
二、翻译器使用
============================================================

翻译流程

  1. 目标语言：选翻译成什么语言（默认简体中文）
  2. 上传文件：拖入 .pdf / .docx / .pptx
  3. 双语 PDF 质量：默认「标准 · 推荐」即可
  4. 先试翻：勾选「试翻」→ 只翻前 5 页看效果和费用
  5. 全量翻：满意后取消勾选，再点开始


输出在哪

  trans_result\书名_xxxxxx\
  ├── translated.pdf              纯译文（推荐先看）
  ├── translated_with_notes.pdf   术语表 + 译文
  ├── bilingual.pdf               左右对照（体积最大）
  ├── _书名\                      术语笔记
  │   ├── notes.html              浏览器打开，鼠标悬停查词
  │   └── terms.csv               Excel 打开
  └── _work\                      中间文件（不要动）


中途想停

  停某一个：右侧下拉选任务 → 点「停止选中」
  全停：点左边「全部停止」

  停了进度会保存，下次从断点继续，不重复扣费。


============================================================
三、解题器使用
============================================================

解题流程

  1. 上传作业：拖入 .pdf / .docx / .pptx
  2. 先试解：勾选「试解模式」→ 只处理前 5 页
  3. 看效果：满意后取消勾选，再全量跑


效果

  答案：红色，写在题目块底部
  解析：蓝色 + 浅蓝底，贴在题目下方
  数学公式：用 matplotlib mathtext 渲染成图片贴入
          支持 \frac \sqrt \sum \int 等基本 LaTeX


输出在哪

  homework_result\文件名_hash\
  ├── solved.pdf          已写答案和解析的作业
  └── _work\              中间文件（不要动）


解题器的限制

  - 只处理含文字层的 PDF。扫描件 / 纯图片题无法识别。
    判断方法：鼠标在 PDF 里能选中文字 → 能处理；选不中 → 先 OCR
  - Word / PPT 里的文本框、页眉页脚、SmartArt → 处理不到


============================================================
四、常见问题
============================================================

Q1：字体放在别的位置怎么办？

  打开 .env，加一行：

      TRANSLATE_FONT_PATH=D:\你\放字体\的地方\SourceHanSerifSC-Regular.otf

  程序会自动扫描 D:\file\translate\word_type\ 和 项目目录\fonts\。


Q2：PDF 里的中文显示成方框？

  字体没设置好。跑一下 test.py 检查：

      conda activate trans
      python test.py


Q3：翻完发现有几页还是原文？

  重新上传同一个文件，点开始。
  程序会自动扫描缺页补翻，已翻好的不重复扣费。


Q4：程序中途崩了怎么恢复？

  重新打开程序，重新上传同一个文件（文件名必须一致），
  点开始，从断点继续。


Q5：能同时跑多个文件吗？

  可以。多任务并行，互不干扰。


Q6：网页打不开？

  翻译器会在 7860~7869 自动找端口，解题器在 7870~7899。
  真实网址会打印在终端里，也保存在：

      访问网址.txt          （翻译器）
      访问网址_解题器.txt   （解题器）

  双击 打开网页.bat 开翻译器，双击 打开解题网页.bat 开解题器。


Q7：扫描版 PDF 能翻 / 能解吗？

  翻译器：不能，需要先 OCR。
  解题器：不能，模型看不见图片。


Q8：.doc / .ppt 老格式能用吗？

  不能。用 Office 打开后另存为 .docx / .pptx 再上传。


Q9：翻译成阿拉伯语 / 俄语效果好吗？

  PDF 模式建议只翻中 / 日 / 韩，因为电脑上可能没有对应字体。
  Word / PPT 没限制，用原文档字体。


Q10：翻译费用大概多少？

  DeepSeek 很便宜，一本 300 页的书约 3~5 元。

  先试翻 5 页，看后台实际扣费 x（总页数 / 5）就是全书估算。

  会重新扣费：删了缓存、改了原文、换了目标语言
  不会扣费：  暂停后继续、崩溃后重来、换质量档位
